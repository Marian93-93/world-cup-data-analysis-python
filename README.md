# ⚽ FIFA World Cup Data Analysis & Insights

## 📌 Project Overview
This project performs an end-to-end Exploratory Data Analysis (EDA) on historical FIFA World Cup datasets using Python. The goal is to clean, transform, and analyze match and tournament statistics to uncover key trends, team performance metrics, and goal distribution patterns across tournament editions.

---

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Data Manipulation & Cleaning:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Data Source:** FIFA World Cup Historical Dataset

---

## 🔍 Key Questions Answered
* Which national teams have the highest win rates and goal averages?
* How has the average number of goals per match evolved across tournaments?
* What are the most common match outcomes and home-advantage trends?
* Top performing players and tournament attendance trends over the years.

---

## 📊 Workflow
1. **Data Cleaning & Preprocessing:** Handled missing values, standardized country names, and formatted match dates.
2. **Feature Engineering:** Extracted tournament stages, calculated goal margins, and categorized match results.
3. **Exploratory Data Analysis (EDA):** Built descriptive statistics and comparative visual distributions.
4. **Insights Extraction:** Summarized analytical findings into actionable statistical observations.
